Copy the share link of any review on Google Maps (Three Dots -> Share review -> Copy link) and paste it into reviewsToCheck. The Actor returns status: 'ACTIVE' (is_removed: false) if live, or status: 'REMOVED' (is_removed: true) if deleted.
